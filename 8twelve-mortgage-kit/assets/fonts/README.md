# First-page typography

Self-hosted font files from the Google Fonts repository. Used on all four presentation pages.

- DM Serif Display regular and italic: https://github.com/google/fonts/tree/main/ofl/dmserifdisplay
- Manrope variable (weights 200–800): https://github.com/google/fonts/tree/main/ofl/manrope

Each family is licensed under the SIL Open Font License 1.1. The corresponding `*-OFL.txt` files are included here. No external font request is made by the page.
